# beyondbob Jekyll 초안 설계

2026-09-15. 사용자는 앞서 제시한 프로젝트 허브 구조를 바탕으로 초안 작성을 요청했다.

## 범위

- 팀: beyondbob. 장민석, 김충식, 류준. 역할·프로필은 미정.
- 확정 트랙: 소상공인·골목상권 디지털 금융.
- 세무·매출 AI 도우미, 청년창업 매칭, 골목상권 AI 컨설팅은 트랙의 세 후보 기능으로 설명한다. 모두 구현한다고 확정하지 않는다.
- 프로젝트 허브, 사진 기준 1~6 및 5.1 산출물, 진행 현황, 개발 기록, 팀, 출품 자료를 제공한다.
- 기능·성능·프로필·배포 상태에 대한 실적을 만들어 넣지 않는다.

## 구현

Jekyll 4.4.1과 Just the Docs 0.12.0을 사용한다. 테마의 검색·계층형 메뉴를 유지하고, 팀 전용 홈·문서·기록 레이아웃 및 반응형 CSS를 추가한다. 사용자에게 제공된 원본 자료와 내부 설계 문서는 빌드에서 제외한다. 팀·일정·산출물·작업 데이터는 YAML에서 관리한다. 실시간 API나 실제 업무 처리 기능은 이 문서 사이트의 범위에 포함하지 않는다.

## 검증

실제 Jekyll 빌드, 생성된 HTML의 로컬 링크·앵커, 제외 파일 유출, 데스크톱·모바일 레이아웃, 한국어 검색과 모바일 메뉴를 확인한다. 문서·스타일 중심 초안이므로 구현을 그대로 반복하는 단위 테스트는 추가하지 않는다.
