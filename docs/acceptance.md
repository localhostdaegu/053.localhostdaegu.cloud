## 검수 기준

검수 범위와 실행 환경이 정해지면 요구사항별 통과 조건을 확인합니다. 현재 서비스 검수는 실행 전이며, 고객 환경 구축·이전 여부는 미정입니다.

## 개발 환경 — HW / SW

| 항목 | 기록할 내용 | 현재 상태 |
|---|---|---|
| HW | CPU·GPU·메모리·저장공간 | 서비스 환경 미정 |
| SW | OS·런타임·라이브러리·DB·모델 | 서비스 버전 미정 |
| 네트워크 | 도메인·포트·외부 연결 조건 | 배포 환경 미정 |
| 검수 버전 | 소스 커밋·모델·데이터 버전 | 등록 전 |

## 개발 내용 Flow와 동작 과정

시작 → 설정 확인 → 입력 → 데이터 처리 → AI 추론 → 결과 확인 → 로그 확인 → 종료의 실제 경로를 검수합니다. 선택한 MVP 기준으로 [상세 설계]({{ '/docs/detailed-design/' | relative_url }})와 일치하는지 확인합니다.

## 설치·소스 이전 매뉴얼

1. 소스 저장소와 검수 버전 확인
2. 런타임과 의존성 설치
3. 환경 설정과 자격증명 주입
4. DB 구성과 샘플 데이터 준비
5. AI 모델 또는 외부 서비스 설정
6. 서비스 실행과 정상 기동 확인
7. 핵심 시나리오 재현
8. 로그 확인·종료·재시작

실제 실행 명령은 서비스 구현 후 검증한 내용을 기록합니다. **이 Jekyll 문서 사이트의 실행 방법은 저장소 README에 별도로 정리**합니다.

## 로컬 → AWS 등 환경 이전

| 확인 항목 | 기록할 내용 |
|---|---|
| 이전 대상 | 애플리케이션·DB·모델·파일 중 이동할 범위 |
| 환경 대응 | 로컬 설정과 대상 환경 설정의 차이 |
| 데이터 이전 | 백업·복원·정합성 확인 절차 |
| 연결 확인 | 도메인·TLS·외부 API·DB 연결 |
| 재검증 | 같은 입력에서 결과와 성능 차이 확인 |
| 복구 | 이전 실패 시 되돌리는 절차 |

현재 클라우드 공급자와 이전 대상은 확정하지 않았습니다.

## 사용자 설정·예외 처리

사용자가 조정하는 값의 범위·기본값·반영 시점을 확인하고 잘못된 설정, API 실패, 데이터 부족에 대한 동작을 검수합니다.

## 유지보수와 검수 결과

- [ ] 설치·실행 절차 재현
- [ ] 사용자 설정 확인
- [ ] 정상·오류 테스트 재실행
- [ ] 로그·백업·복구 절차 확인
- [ ] 알려진 제한과 미해결 결함 기록
- [ ] 검수 일자·버전·수행자·판정 기록

현재 판정: **미실행**. 테스트 번호별 상세 결과는 [시나리오 테스트]({{ '/docs/testing/' | relative_url }})에 연결합니다.
