## 추가 공공데이터 5종 — 적재·화면 연결 완료

9월 18일 조사 후 9월 19일 5종 모두 적재하고 지도 패널의 동네 특성·시간대별 승차에 연결했습니다. 아래 규모·기준일은 조사 원본 기준입니다. 좌표가 필요한 역·백년가게는 SGIS로 변환했습니다.

| 데이터 | 출처·형태 | 규모·기준일 | 좌표 | 반영 결과 |
|---|---|---|---|---|
| 전통시장 | 브이월드 API | 대구 좌표 범위 113곳(주소 기준 107곳) | 있음 | 적재·동네 특성 배지 연결. 점포 수 필드의 의미는 재확인 필요 |
| 나들가게 | 공공데이터포털 파일 | 전국 7,136곳 · 9/9 | 위경도 있음 | 적재·동네 특성 배지 연결 |
| 온누리상품권 가맹점 | 공공데이터포털 파일 | 전국 125,589곳 · 9/9 | 주소만 | 행정동 지표 적재·동네 특성 배지 연결 |
| 백년가게 | 공공데이터포털 파일 | 전국 1,511곳 · 8/30 | 주소만 | 행정동 지표 적재·동네 특성 배지 연결 |
| 대구교통공사 역별 승하차 | 공공데이터포털 파일 + 역 좌표 파일 | 39,856행 · 9/3 | 없음 | 역 좌표 연결·시간대별 승차 표시(역이 있는 56개 동) |

초기에는 마감 전 범위를 두 가지로 줄였지만(DEC-016), 9/19에는 5종 전체를 완료했습니다. 상세는 [개발 기록]({{ '/journal/2026/09/19/deploy-persona-metrics/' | relative_url }})에 남겼습니다.

## 기술 적용 원칙

- **AI 중심으로 구현합니다.** 블록체인 앵커링은 9/18 결정으로 범위에서 제외했습니다. 상담자료의 sha256 해시는 내용 변경 확인용으로 서버에 기록합니다([DEC-018]({{ '/decisions/' | relative_url }})).
- **숫자는 코드가, 해석은 AI가 씁니다.** 위험도 점수·지표·부족 자금·매칭 상품은 코드가 계산하고, AI(Gemini)는 그 결과와 검색한 공고·뉴스를 바탕으로 해석 문단만 작성합니다.
- **확인하지 않은 데이터와 연동은 쓰는 것처럼 설명하지 않습니다.** 센터 데이터와 추가 공공데이터는 확보·적재한 뒤에만 서비스 설명에 넣습니다.
