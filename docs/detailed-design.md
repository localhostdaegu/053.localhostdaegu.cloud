## 개발 개요·목적·기능

최종 선정된 MVP의 구현 범위, 사용자 흐름, 실제 사용 기술을 이 절에 기록합니다. 현재 서비스명·우선 기능·API 계약은 미정입니다.

## 실제 Data Flow

현재의 [상위 설계 흐름도]({{ '/docs/architecture/' | relative_url }})는 검토안입니다. 구현 후에는 실제 호출 순서, 입출력 값, 저장 위치, 실패 경로를 반영해 구현 기준의 흐름도로 갱신합니다.

## 요구사항별 상세 설계 기록

| 기록 항목 | 작성할 내용 |
|---|---|
| 요구사항 번호 | REQ-001 / REQ-002 / REQ-003 및 관련 품질 요구사항 |
| 구현 범위 | 구현한 동작과 이번 범위에서 제외한 동작 |
| 근거 | 소스 파일·함수·커밋 또는 버전 |
| 입력·출력 | 데이터 형식, 필수·선택 값, 정상·실패 응답 |
| 처리 과정 | 조회 → 변환·계산 → AI 호출 → 결과 검토 → 반환 |
| 저장 구조 | 실제 테이블·필드·관계·보관 정책 |
| 실패 처리 | 검증 실패·타임아웃·외부 오류·데이터 부족 |
| 검증 연결 | 테스트 번호와 실제 실행 결과 |

### REQ-001 · 세무·매출 AI 도우미

구현 방식 미정. 지원 자료 형식, 집계 규칙, AI 설명 생성 범위와 원본 연결 방법을 구현 후 기록합니다.

### REQ-002 · 청년창업 매칭

구현 방식 미정. 조건 표현, 정보 갱신, 후보 선정 규칙, 제외 이유 표시 방법을 구현 후 기록합니다.

### REQ-003 · 골목상권 AI 컨설팅

구현 방식 미정. 지역·업종 단위, 지표 계산, 비교 기준, 설명과 제안의 생성 방법을 구현 후 기록합니다.

## API와 데이터 모델

API 경로와 요청·응답 스키마, ERD는 실제 서비스 계약을 정한 뒤 추가합니다. 이 문서 초안에는 동작하지 않는 예시 API를 실제 엔드포인트로 기재하지 않습니다.

## 애플리케이션 설정과 예외 처리
{: #configuration }

| 구분 | 기록할 항목 | 확인 기준 |
|---|---|---|
| 모델 설정 | 모델명·버전·입출력 제한·생성 설정 | 같은 설정으로 실행 가능 |
| 연결 설정 | API·DB 주소, 타임아웃, 인증 설정 방법 | 비밀값을 제외한 설정 예시 제공 |
| 재시도 | 적용 오류·횟수·대기·중복 방지 | 실패 시나리오로 확인 |
| 데이터 부족 | 판단 중단·부분 결과·추가 입력 안내 | 없는 자료를 생성하지 않는지 확인 |
| 사용자 설정 | 지역·업종·기간 등 확정된 설정 | 값의 범위와 기본값 설명 |
| 관측 | 로그·오류·응답시간·버전 기록 | 테스트 결과와 실행 기록 연결 |

## 상위 설계와 달라진 점

현재 등록된 변경 없음. 차이가 생기면 변경 전·후, 변경 이유, 영향을 받는 요구사항과 재검증 결과를 남깁니다.
