<div class="notice"><strong>범위 검토 중</strong><br>아래 요구사항은 세 후보 기능을 논의하기 위한 초안입니다. 우선순위, 지원 데이터 형식, 외부 연동, 수치 기준은 아직 확정하지 않았습니다.</div>

## 개발 개요

소상공인과 청년 창업가가 자료와 정보를 이해하고 다음 행동을 결정하는 과정을 지원합니다. 모든 기능 설명은 데이터 확보와 사용자 시나리오 확인을 통해 구체화합니다.

## REQ-001 · 세무·매출 AI 도우미
{: #req-001 }

| 항목 | 검토안 |
|---|---|
| 사용자 요구 | 매출·정산·증빙 자료의 내용을 쉽게 이해하고 싶다. |
| 입력 후보 | 사용자가 제공한 매출·정산 자료. 형식과 연동 방식 미정. |
| 출력 후보 | 기간별 요약, 누락·불일치 확인 항목, 설명과 원본 근거 |
| 필수 조건 제안 | 계산값과 AI 설명을 구분하고 사용한 원본 항목으로 돌아갈 수 있어야 한다. |
| 범위 검토 | 세무 정보 안내와 자료 정리의 경계를 정한다. 신고 대행·세액 확정 기능은 별도 논의가 필요하다. |
| 검증 방향 | 정답이 있는 샘플 자료에서 집계 일치와 근거 연결 확인 |
| 연결 테스트 | TC-001, TC-004 |

## REQ-002 · 청년창업 매칭
{: #req-002 }

| 항목 | 검토안 |
|---|---|
| 사용자 요구 | 자신의 창업 조건에 맞는 지원 정보와 연결 기회를 찾고 싶다. |
| 입력 후보 | 희망 지역·업종·창업 단계·관심 조건 |
| 출력 후보 | 후보 정보, 매칭 이유, 원문 링크, 기준일 |
| 필수 조건 제안 | 확인된 정보와 충족하지 못한 조건을 구분해서 보여줘야 한다. |
| 범위 검토 | 지원 사업·공간·멘토·금융 등 무엇을 매칭할지 먼저 선택한다. |
| 검증 방향 | 조건이 명확한 샘플에서 적합·부적합 판단과 원문 일치 확인 |
| 연결 테스트 | TC-002, TC-004 |

## REQ-003 · 골목상권 AI 컨설팅
{: #req-003 }

| 항목 | 검토안 |
|---|---|
| 사용자 요구 | 특정 골목과 업종의 데이터를 이해하고 운영·창업 판단에 참고하고 싶다. |
| 입력 후보 | 대상 지역·업종·분석 질문과 확보한 상권 데이터 |
| 출력 후보 | 핵심 지표, 지표 해설, 확인할 사항, 실행 제안 |
| 필수 조건 제안 | 데이터 출처·지역 범위·기준 시점을 표시하고 관측값과 해석을 구분해야 한다. |
| 범위 검토 | 대상 상권, 지표, 비교 기간과 공간 단위 선정 |
| 검증 방향 | 원자료와 지표 일치, 설명의 근거, 데이터 부족 처리 확인 |
| 연결 테스트 | TC-003, TC-004 |

## 공통 기술·품질 요구사항

| 번호 | 요구사항 제안 | 판정 방법 | 현재 상태 |
|---|---|---|---|
| NFR-001 | 결과의 출처·기준일을 확인할 수 있다. | 결과와 출처 연결 확인 | 검토 중 |
| NFR-002 | 잘못된 입력·데이터 부족·API 실패를 설명한다. | 예외 시나리오 실행 | 검토 중 |
| NFR-003 | 처리량과 응답시간을 구간별로 측정할 수 있다. | 요청 시작·종료·실패 기록 | 목표값 미정 |
| NFR-004 | 동일 데이터와 설정으로 검증을 재현할 수 있다. | 버전·설정·데이터 기록 | 검토 중 |
| NFR-005 | 필요한 데이터만 처리하고 자격증명을 코드와 분리한다. | 입력·저장 항목 및 설정 검토 | 검토 중 |
